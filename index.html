SOW·33 K.O! の使い方

パッド: タップで即発音。1–8 メロディ / 9–16 ドラム。

PLAY: 再生/停止。初期状態でデモパターン（ドラム＋メロディ）が入っています。

SYNTH: メロディ音色を巡回 SIMPLE → FM → WAVE → ADD。

SOUND+パッド: 編集対象の音を選択。ノブA=ピッチ / B=ディケイ。

WRITE: 点灯中にパッドでステップON/OFF。再生中ならリアルタイム録音。

PATTERN+パッド: パターン選択、続けてタップでチェーン。

BPM: 点灯中にノブAで 60–240。

FX: 点灯中にパッド1=FILTER / 2=DELAY / 3=DRIVE を選び、ノブA/Bで操作。

MIC: 点灯中にパッドをタップ→約1.5秒マイク録音してそのスロットに割当。

JAM: ランダムパターン生成＆再生。SAVE/LOAD: パターン保存。

LOAD 長押し: プリセット読込（ZOMBIE: Em→C→G→D の 4 小節ループ、84 BPM）。読込後 PLAY。

iPhoneで音が出ない時: サイレントスイッチOFF・音量を確認。LCD左上の RUN/SUSP/INTR が Context の状態、+P / +M が消音スイッチ対策の適用済み表示です。タップして閉じる
